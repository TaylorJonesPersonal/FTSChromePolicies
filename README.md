# FTSChromePolicies
This repository hosts the ongoing changes to the FTS links.

<img width="96" height="41" alt="image" src="https://github.com/user-attachments/assets/ed08e889-feff-43a9-ab9d-19d93f47cc27" />


These links are Chrome Bookmarks that are pushed by Group Policy to machines managed under FTS AD/OU.
They are then administered to Chrome and can be seen at chrome://policy

## Husky
The repo attempts to lint and check the validity of the JSON file with a husky pre-commit. This can also be accomplished using:
`npx lint-staged`
